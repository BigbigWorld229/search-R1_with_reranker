# 代码目录说明

本仓库包含强化学习训练入口、排序数据处理、检索服务、分布式训练框架、配置管理和运行工具。下面按目录说明各部分代码的职责。

## 根目录

根目录提供训练流程的主要入口和数据集适配模块：

- 训练入口负责读取 Hydra 配置、初始化 Ray 集群、划分计算资源、注册策略模型与排序模型的工作进程，并启动分布式强化学习训练器。
- 数据集适配模块负责读取 Parquet 数据、校验提示词与奖励字段，并提供普通生成数据集和强化学习数据集两种接口。
- `.gitmodules` 记录外部检索子模块的位置。
- `.gitignore` 定义数据、检查点、日志、缓存、实验输出和本地环境文件的忽略规则。

## `conda_setup/`

该目录负责训练环境的创建与依赖安装：

- 环境初始化脚本创建或更新 Conda 环境，并安装 Python、CUDA、PyTorch及训练框架依赖。
- 目录内说明文档记录 CUDA 版本、环境重建和可选依赖等参数。

## `config/`

该目录集中管理 Hydra 配置和配置数据结构：

- `actor/`：策略模型训练、分布式并行和参数更新配置。
- `algorithm/`：优势估计、KL 约束、奖励处理和回放修正等算法配置。
- `critic/`：价值模型的训练与并行配置。
- `data/`：训练集、验证集、批大小和输入长度配置。
- `engine/`：FSDP、Megatron等执行后端配置。
- `model/`：主模型与排序模型的加载、精度和检查点配置。
- `npu_profile/`：NPU 性能分析相关配置。
- `optim/`：优化器、学习率和梯度处理配置。
- `ref/`：参考策略模型配置。
- `reward_model/`：奖励模型及其资源分配配置。
- `rollout/`：同步或异步生成、采样参数和推理后端配置。
- 目录根部的 Python 与 YAML 文件负责组合上述配置，并为训练、生成、评测和监督微调提供完整参数入口。

## `Search-R1/`

该目录是外部检索与推理代码的 Git 子模块，提供检索语料处理、向量索引、检索服务以及带工具调用的搜索流程。主仓库通过子模块引用固定版本，避免直接复制其完整历史。

## `scripts/`

该目录提供运行辅助工具：

- 下载训练与评测数据并保存到本地数据目录。
- 启动向量检索服务，加载语料、索引和检索模型。
- 组装运行时配置并提交分布式训练任务。

## `verl/`

该目录包含分布式强化学习训练框架及其扩展实现：

- `verl/`：核心 Python 包，包含数据协议、单控制器、工作进程、训练器、模型接口、奖励计算、检查点和通用工具。
- `verl/experimental/`：多轮智能体循环、工具调用、异步生成、轨迹处理和实验性训练组件。
- `verl/trainer/`：PPO 等训练算法、指标统计、资源调度和排序模型联合训练逻辑。
- `verl/workers/`：策略模型、参考模型、价值模型、奖励模型及生成服务的分布式工作进程。
- `examples/`：数据预处理、生成、监督微调和多种强化学习训练方式的示例。
- `recipe/`：针对不同算法与任务组合的训练配方和扩展组件。
- `tests/`：配置、数据协议、控制器、训练器、工作进程和端到端流程的自动化测试。
- `docs/`：框架架构、配置方法、性能优化和各类后端的使用文档。
- `docker/`：不同 CUDA、ROCm 和硬件环境的容器构建文件。
- `scripts/`：模型格式转换、配置生成、环境安装和运行诊断工具。
